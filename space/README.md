# Herbarium specimen identification

Family-level identification of African angiosperms (both dicots and
monocots) from herbarium sheet images. Upload a specimen and the
model returns the top-5 predicted families.

Models hosted under [ggosline](https://huggingface.co/ggosline) — see
the model card for each entry in the picker for training details and
data provenance.

Source pipeline: <https://github.com/ggosline/herbarium-pipeline>
